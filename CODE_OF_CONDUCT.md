# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the work, and make room for people who are new. Harassment of any kind is not welcome.

To report a problem, use GitHub's private reporting (the repository's **Security** tab) or contact the maintainer through their GitHub profile. Reports are kept confidential.
